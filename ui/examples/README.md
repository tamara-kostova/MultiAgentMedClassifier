# UI example scans

`ui/demo.py` shows every image in `ui/examples/<task>/` as an example, and clicking one also
selects `<task>` (`binary_tumor`, `multiclass_tumor`, `ms`, `stroke`). Keep the files small
(one 2D slice, PNG/JPEG) and only add images whose license allows redistribution.

| File | Source |
|---|---|
| `binary_tumor/figshare_t1c_coronal.jpg`, `multiclass_tumor/figshare_t1c_coronal.jpg` | Figshare brain tumor dataset (Cheng et al., 2017), CC BY 4.0. T1-weighted contrast-enhanced, coronal. |
